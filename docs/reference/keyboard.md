# Keyboard

This page lists the keys of Pivots and Scripts.

## What it does

Every button, box and list can be reached with the keyboard. A focus frame shows the control that has the focus.

## When to use it

Use it to work without a mouse.

## Requirements

None.

## Steps

None.

## Options and settings of this page

| Key | Effect |
|---|---|
| Tab, Shift+Tab | Move the focus. |
| Enter, Space | Press the focused button. |
| Ctrl+Space | In the editor: open the starter list of entities and operators (CMPivot) or of cmdlets and keywords (PowerShell). |
| Up, Down | Move in a grid or a list. |
| Esc | Close a dialog, as **Cancel**. |

## Limits

- The order of the Tab key follows the layout of the window: sidebar, target box, editor, buttons, result grid.
- A double-click on a library entry opens it in the editor. The keyboard way is **Open Query or Script**.
- The Tab order of the dialogs was not checked in this guide.

## Troubleshooting

| Message or symptom | Cause | Fix |
|---|---|---|
| A button is skipped. | The button is disabled, for example **Stop Waiting** when no run is active. | Start a run first. |
