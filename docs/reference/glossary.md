# Glossary

This page defines the terms of Pivots and Scripts.

## What it does

It gives one short definition for each term that the tool and this guide use.

## When to use it

Use it when a term is not clear.

## Requirements

None.

## Steps

None.

## Options and settings of this page

| Term | Meaning |
|---|---|
| Administration service | The REST service of the SMS Provider. CMPivot runs through it, over HTTPS. |
| CMPivot | The Configuration Manager feature that runs a query on the live state of devices. |
| Operation ID | The number that the site gives to a run. The tool reads the results of that operation. |
| Pipeline | The tab that lists each step of the session. |
| Resolve | The action that turns the target text into a list of devices. |
| Run Scripts | The Configuration Manager feature that runs an approved PowerShell script on devices. |
| Script GUID | The identifier of a script on the site. |
| Session | The saved record of all steps of one work period. |
| Site Code | The 3-character code of a Configuration Manager site. |
| SMS Provider | The server role that gives access to the site data. |
| Snapshot | The fixed list of resolved devices. |
| Step | One run in a session: a CMPivot query or a script, with its targets and results. |
