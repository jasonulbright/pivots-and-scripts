# Pivots and Scripts documentation

Pivots and Scripts sends a CMPivot query or an approved Run Scripts script to a set of Configuration Manager devices and shows the answers as they come in. This page links every page of the documentation.

## Start

- [Getting started](getting-started.md): install, set the connection and test it.

## Core

- [Targets](core/targets.md): resolve a collection, a device, a pattern or a list into a fixed snapshot.
- [CMPivot](core/cmpivot.md): the library, the query editor and Run CMPivot.
- [Run Scripts](core/run-scripts.md): write a script, submit it, set the parameters and run an approved script.
- [Results](core/results.md): the Results, Devices, Raw and Pipeline tabs, export, copy and Selection to Pivot or Script.
- [Sessions](core/sessions.md): save, open and start a session.
- [Options dialog](core/options.md): Connection, Run Scripts and About, and the theme.
